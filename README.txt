خطوات التشغيل المجاني في 5 دقائق:

1) استخراج مفتاح الذكاء الاصطناعي المجاني:
   - ادخل إلى: https://aistudio.google.com
   - اضغط Get API key ثم Create API key وانسخ المفتاح.

2) رفع الملفات على GitHub مجاناً:
   - أنشئ حساباً على https://github.com
   - اضغط New Repository وسمّ المشروع: miraa-pro
   - ارفع جميع الملفات الموجودة داخل هذا المجلد (index.html و vercel.json ومجلد api وبداخله analyze.js).

3) الإطلاق على Vercel مجاناً:
   - ادخل إلى https://vercel.com وسجّل الدخول بحساب GitHub.
   - اضغط Add New -> Project واختر miraa-pro.
   - افتح Environment Variables وأضف:
       Key: GEMINI_API_KEY
       Value: (الصق مفتاح Google AI Studio هنا)
   - اضغط Deploy.
   - خلال أقل من دقيقة سيعطيك Vercel رابط موقعك الحي جاهزاً للإرسال للعملاء!
